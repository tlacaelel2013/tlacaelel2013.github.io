# AI-mericans GitHub 1.11

The USCIS Practice controller now keeps a stable `{stage, question index, question ID}` snapshot for every submitted response. Interview feedback is calculated locally for the exact current question, so a GGUF abort cannot freeze the screen, repeat question one, or compare later responses with “Yes, I do.”

The separate Chat Room remains available for optional GGUF conversation. Version 1.11 retains the 128-question civics bank, introduction and N-400 practice sections, GGUF download menu, local GGUF picker, dictation, and Listen to Officer control.

Run `START-AI-MERICANS.command`, open the printed local address, and use a hard browser refresh when replacing an older version.
