# MathHike Demo Guide

- **Python Trail:** run the built-in scientific Python examples or `examples/python-mountain.py`.
- **R Trail:** initialize webR and try `examples/r-histogram.R`.
- **Linux Trail:** choose a supported TinyEMU/browser machine. Large root images are intentionally not bundled in this public ZIP.
- **Tutor:** use the local/browser GGUF path appropriate to this edition.
- **Library:** open a local PDF and use page-range / translation companion tools.

The deterministic R/Python/Linux trail output is the source of computed truth; the AI tutor explains rather than replacing it.
