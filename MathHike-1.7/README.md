# MathHike GitHub 1.1 Full Classroom

This is the real feature-rich successor to 0.7 Library. It preserves the dashboard, R/webR, scientific Python/Pyodide, Linux/TinyEMU browser lab and source tree, browser-local GGUF/Wllama tutor, Library/PDF tools, and classroom trails. It adds a Demo Guide and examples from the newer publishing companion.

Publish from HTTPS/GitHub Pages. Large OS/root images and GGUF models are intentionally not committed. Third-party components retain their own licenses.
